# 🏋️ 스마트 데일리 운동 루틴 추천 프로그램

1주차에 제작한 C++ 콘솔 기반 운동 루틴 추천 프로그램을 웹브라우저와 스마트폰에서 직관적으로 사용할 수 있도록 변환한 웹 애플리케이션입니다.

## ✨ 주요 기능
- **분할 방식 선택:** 4분할 루틴 및 3분할(PPL) 루틴 전환 지원
- **요일별 루틴 조회:** 월요일(1)~일요일(0) 선택 시 타겟 부위 및 주요 운동 종목 안내
- **오늘 요일 자동 선택:** 접속한 날짜의 요일을 자동으로 인식하여 당일 루틴 즉시 표시
- **운동 달성률 체크:** 종목별 권장 세트·자세 팁 제공 및 클릭 시 완료 체크와 실시간 진행률(%) 표시
- **주간 전체표 보기:** 선택한 분할 방식의 일주일 전체 스케줄 한눈에 비교

## 📱 사용 방법
1. 상단에서 **4분할 루틴** 또는 **3분할 (PPL)** 중 원하는 분할 방식을 선택합니다.
2. **요일 버튼(월~일)**을 클릭하거나 **📅 오늘 요일 자동 선택** 버튼을 누릅니다.
3. 추천된 운동 종목 카드를 확인하고, 운동을 마친 종목은 클릭하여 달성률을 체크합니다.
